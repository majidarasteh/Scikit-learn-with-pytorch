# Tutorial: How to Choose a Scikit-learn Estimator

Scikit-learn provides many machine-learning algorithms, called estimators. Choosing the right algorithm can be difficult for beginners.

The Scikit-learn cheat sheet is a flowchart that helps us decide which algorithms to try based on our problem and dataset.

The main categories are:

- Classification: Predict a category.
- Regression: Predict a numerical value.
- Clustering: Group similar observations.
- Dimensionality reduction: Reduce the number of features.

The flowchart provides suggestions, not guaranteed answers. We should test different algorithms to find which works best for our data.

## 1. Start by examining your data

The flowchart begins by considering the number of samples.

A sample is one observation or row in a dataset. For example, one patient's record is one sample in a heart disease dataset.

The flowchart uses thresholds such as 50, 10,000, and 100,000 samples to suggest possible algorithms. These are rough guidelines, not strict rules.

Next, ask yourself: Do I have labeled data?

- Labeled data: Each sample has a known target value.
- Unlabeled data: There is no target value for each sample.

This helps determine which type of machine learning to use.

## 2. Classification

Classification predicts a category or class.

Examples:

- Predict whether an email is spam.
- Predict whether a patient has heart disease.
- Classify an image as a cat or a dog.

The target contains categories such as `Yes/No` or `Spam/Ham`.

The cheat sheet suggests several algorithms:

| Algorithm                 | Simple explanation                      |
| ------------------------- | --------------------------------------- |
| Naive Bayes               | Often useful for text classification    |
| K-Nearest Neighbors (KNN) | Predicts using similar observations     |
| SVC                       | Finds a boundary that separates classes |
| Ensemble Classifiers      | Combines multiple models                |
| SGD Classifier            | Trains linear classifiers efficiently   |

Example: For SMS spam detection, we could start with Naive Bayes or Linear SVC.

## 3. Regression

Regression predicts a numerical value.

Examples:

- Predict house prices.
- Forecast Bitcoin prices.
- Predict electricity consumption.

The cheat sheet suggests algorithms such as:

| Algorithm           | Simple explanation                                                        |
| ------------------- | ------------------------------------------------------------------------- |
| Linear Regression   | Models a linear relationship                                              |
| Ridge Regression    | Linear regression with L2 regularization                                  |
| Lasso               | Linear regression with L1 regularization; can remove less useful features |
| ElasticNet          | Combines L1 and L2 regularization                                         |
| SVR                 | Predicts numerical values using support vector methods                    |
| Ensemble Regressors | Combines multiple models                                                  |
| SGD Regressor       | Trains linear regression models efficiently                               |

> L1 and L2 regularization are techniques used to reduce overfitting by adding a penalty to the model's loss function. L1 regularization (Lasso) penalizes the absolute values of model coefficients and can make some coefficients exactly zero, effectively removing less important features. L2 regularization (Ridge) penalizes the squared values of coefficients, shrinking them toward zero without usually making them exactly zero. Both methods help control model complexity and improve performance on unseen data.
Example: To predict house prices, we could compare Linear Regression, Ridge, and a tree-based ensemble model.

## 4. Clustering

Clustering groups similar observations without using known target labels.

Examples:

- Group customers by purchasing behavior.
- Find groups of similar documents.
- Discover communities in social networks.

The cheat sheet suggests algorithms such as:

| Algorithm                    | Simple explanation                                                       |
| ---------------------------- | ------------------------------------------------------------------------ |
| K-Means                      | Groups observations into a specified number of clusters                  |
| MiniBatchKMeans              | A more computationally efficient variation of K-Means for large datasets |
| MeanShift                    | Finds groups based on data density                                       |
| Gaussian Mixture Model (GMM) | Models data as a mixture of probability distributions                    |
| Spectral Clustering          | Uses similarities between observations to form clusters                  |

If you know the number of clusters, K-Means is often a reasonable starting point. If you do not know the number, you can explore methods such as MeanShift or GMM.

## 5. Dimensionality reduction

Dimensionality reduction reduces the number of features while trying to preserve useful information.

For example, a dataset with 100 features might be transformed into two dimensions for visualization.

The cheat sheet suggests methods such as:

| Algorithm          | Simple explanation                                                                   |
| ------------------ | ------------------------------------------------------------------------------------ |
| PCA                | Finds directions that explain the most variance                                      |
| Randomized PCA     | An approximate PCA method                                                            |
| Isomap             | Attempts to preserve distances along the data's underlying structure                 |
| Spectral Embedding | Uses relationships between observations to create a lower-dimensional representation |
| LLE                | Attempts to preserve local relationships between observations                        |

Example: PCA can reduce a dataset with many numerical features to two components so we can plot the observations in a 2D graph.

## 6. How should we use the cheat sheet?

Follow these simple steps:

1. Identify your task: classification, regression, clustering, or dimensionality reduction.
2. Inspect your dataset, including its sample count, features, and target.
3. Follow the corresponding branch of the flowchart.
4. Select a few suggested algorithms.
5. Train and evaluate the models using suitable metrics.
6. Compare the results and tune the most promising model.

For supervised learning, use metrics appropriate to the task. For example, classification can use **accuracy, precision, recall, and F1-score**, while regression can use **MAE, MSE, and RMSE**.

Remember to use a suitable validation strategy and avoid data leakage when preparing your data.
